Global Functions:
kernel/memory.asm
 - initializeMemory -> NO INPUT -> NO OUTPUT : NO STATUS
 - pageAllocate -> AL=SIZE -> EDX=ADDR
 - pageFree -> AL=SIZE,BX=ADDR -> NO OUTPUT : NO STATUS
kernel/container.asm
 - registerContainer -> EDI=PTR,AX=FLAGS,BX=HNDL -> DX=HNDL
 - getRawContainer -> AX=HANDLE -> EDX=PTR
 - deleteContainer -> AX=HANDLE -> NO OUTPUT
kernel/procedure.asm
 - createProcedure -> ESI=NAME,AX=CODE CMHNDL,BL=FLAGS -> DX=PDHNDL
 - registerProcedure -> AX=HNDL -> NO OUTPUT
kernel/link.asm
 - giveContainer -> AX=HNDL,BX=PDHNDL -> NO OUTPUT
 - mapContainer -> AX=HNDL,BX=PDHNDL -> NO OUTPUT
 - mapPageX -> AX=HNDL -> NO OUTPUT : NO STATUS
 - mapDriver -> AX=DDHNDL -> NO OUTPUT : NO STATUS
kernel/scheduler.asm
 - startScheduler -> NO INPUT -> NO OUTPUT : INFINITE
driver/driver.asm
 - registerDriver -> EAX=ADDR -> DX=DDHNDL
 - runDriver -> AX=DDHNDL,BL=SUBFUNC,EDI=STR,ECX=SIZE/ARG,EDX=CINFO -> NO OUTPUT
 - endDriver -> NO INPUT -> NO OUTPUT : NO STATUS
device/device.asm
 - runDevice -> AX=DVHNDL,BL=SUBFUNC,EDI=STR,ECX=SIZE/ARG -> NO OUTPUT
 - createDevice -> AL=TYPE,EBX=CINFO -> DX=DVHNDL : OWNER CURRENT
 - searchDevice -> EAX=CINFO -> DX=DVHNDL

**HNDL structure**:

0     1     2     3     4     5     6     7     8
FLAGS       HNDL        ADDRESS        SZ LINK#

FLAGS
0	1	2	3	4	5	6	7	8
R	W	C	COW	SPC	PDE	SPE	SE
SR	SW	SC	SO	SPR	SPW	SPC	SPO

SPC->Special container
SPC=0,PDE=0 MDHNDL (Miscelaneous Data HaNDLe)
SPC=0,PDE=1 UDHNDL (UnDefined HaNDLe)
SPC=1,PDE=0 UDHNDL (UnDefined HaNDLe)
SPC=1,PDE=1 PDHNDL (Program Data HaNDLe)

Note: UDHNDLs seen as reserved

**DDHNDL structure**:

All functions receive a pointer and size as arguments
0x000: init()= initializes device (only seekable dev_types)
0x004: open()= starts device
0x008: read()= gets data from device
0x00c: misc()= miscelaneous, used for IRQs
0x010: fnsh()= ends device (only seekable dev_types)
0x014: clos()= closes device
0x018: writ()= writes data to device
0x01c: ctrl() = contact info, depends on type
0x020: idrv  = initializes driver itself : NOT A POINTER
0xffc: DDHNDL

INT 0x30 Updates Page at EDX
INT 0x31 Updates IDT
INT 0x32 Updates CR3 (All pages)
INT 0x33 Driver ABI
	DH=0;	pageAllocate
	DH=1;	pageFree
	DH=2;	registerContainer
	DH=3;	getRawContainer
	DH=4;	deleteContainer
	DH=5;	createProcedure
	DH=6;	registerProcedure
	DH=7;	giveContainer
	DH=8;	mapContainer
	DH=9;	registerDriver
	DH=10;	mapDriver
	DH=11;	runDriver
	DH=12;	runDevice
	DH=13;	createDevice
	DH=14;	mapPage1
	DH=15;	mapPage2

**PCI init structure**

Drivers call init(EDI, ECX) to ask PCI to poll devices and look for those devices, and call init() on themselves

*EDI (NASM SYNTAX)

db FLAGS
dw DVHNDL
dd DATA

DATA ACCORDING TO FLAGS
b3=1: DEVICE:VENDOR (DEVICE IF b2 SET)
b3=0: 00|CLASS|SUBCLASS|PROG IF (CLASS IF b2,SUBCLASS IF b1,PROG IF IF b0)
