# ELOS7

**Enhanced Lightweight Operating System v7**

ELOS is an operating system family created in August 2025.

ELOS7 is an experimental x86 operating system written in its entirety in Assembly, built from scratch without relying on an existing operating system kernel or bootloader.

Its architecture revolves around a concept: everything is a handle
